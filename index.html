Syntila Workspace for Linux

Install the headless Workspace service, management CLI and Worker Engine on Ubuntu 22.04 or newer. Packages are available for amd64 and ARM64. Provider CLIs and their logins are installed separately.

Install

Add this signed repository once:

curl --fail --location https://nohainc.github.io/syntila/syntila-archive-keyring.gpg -o /tmp/syntila-archive-keyring.gpg
gpg --show-keys --with-fingerprint /tmp/syntila-archive-keyring.gpg
sudo install -D -m 644 /tmp/syntila-archive-keyring.gpg /etc/apt/keyrings/syntila-archive-keyring.gpg
printf 'Types: deb\nURIs: https://nohainc.github.io/syntila\nSuites: stable\nComponents: main\nSigned-By: /etc/apt/keyrings/syntila-archive-keyring.gpg\n' | sudo tee /etc/apt/sources.list.d/syntila.sources
sudo apt update
sudo apt install syntila

Check the key fingerprint against the publisher's release documentation: 6EA013D12EF79CBDC34D66058182CCCFCF4175F2.

Then, as your normal user:

syntila service install
syntila service start
syntila login
# Open the returned verification URL in your browser and approve sign-in.
syntila login status
# Once phase is complete:
syntila connect
syntila workers check
syntila status

For startup without a login session, enable lingering: loginctl enable-linger "$USER".

Upgrade

After active work finishes:

syntila service stop
sudo apt update
sudo apt install --only-upgrade syntila
syntila service start
syntila status

User state, credentials, sessions and work files are preserved. Package operations do not start a root-owned service or restart running assignments.
