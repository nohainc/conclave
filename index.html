Conclave Workspace for Linux

Install the headless Workspace service, management CLI and Worker Engine on Ubuntu 22.04 or newer. Packages are available for amd64 and ARM64. Provider CLIs and their logins are installed separately.

Install

Add this signed repository once:

curl --fail --location https://nohainc.github.io/conclave/conclave-archive-keyring.gpg -o /tmp/conclave-archive-keyring.gpg
gpg --show-keys --with-fingerprint /tmp/conclave-archive-keyring.gpg
sudo install -D -m 644 /tmp/conclave-archive-keyring.gpg /etc/apt/keyrings/conclave-archive-keyring.gpg
printf 'Types: deb\nURIs: https://nohainc.github.io/conclave\nSuites: stable\nComponents: main\nSigned-By: /etc/apt/keyrings/conclave-archive-keyring.gpg\n' | sudo tee /etc/apt/sources.list.d/conclave.sources
sudo apt update
sudo apt install conclave-workspace

Check the key fingerprint against the publisher's release documentation: 6EA013D12EF79CBDC34D66058182CCCFCF4175F2.

Then, as your normal user:

conclave-workspace service install
conclave-workspace service start
conclave-workspace login
# Open the returned verification URL in your browser and approve sign-in.
conclave-workspace login status
# Once phase is complete:
conclave-workspace connect
conclave-workspace workers check
conclave-workspace status

For startup without a login session, enable lingering: loginctl enable-linger "$USER".

Upgrade

After active work finishes:

conclave-workspace service stop
sudo apt update
sudo apt install --only-upgrade conclave-workspace
conclave-workspace service start
conclave-workspace status

User state, credentials, sessions and work files are preserved. Package operations do not start a root-owned service or restart running assignments.
